# Gabinet Masażu Leczniczego – Beata Stróżna

This repository contains the source code for the professional website of **Beata Stróżna – Gabinet Masażu Leczniczego**, located in Jelcz-Laskowice.

👉 **https://masazleczniczybeata.pl**

The site presents therapeutic massage and rehabilitation services, featuring:

- Professional therapeutic, sports, and relaxation massages  
- Rehabilitation services in Jelcz-Laskowice 
- Online booking / contact information  
- Responsive, modern mobile-first design  

---

## 🧩 Tech Stack

The website is built using:

- **Jekyll** (GitHub Pages)
- **TailwindCSS** (Custom configuration with brand color extensions)
- **Google Apps Script** – Backend processing and handling for the contact form
- **HTML includes** for modular structure (nav, footer, sections)
- **Schema.org** for local SEO optimization
- **Custom typography** (Inter & Geist local fonts)

## 🛠️ Admin Panel & Content Management

- **Sveltia CMS** – A modern, mobile-friendly Git-based content management system.
- Integrated via GitHub backend (`/admin/`), enabling seamless, non-technical updates to the service price list (`_data/cennik.yml`) directly from desktop and mobile devices.

## 🚀 Deployment

The site is automatically deployed using **GitHub Pages**.  
Every push to the `main` branch triggers a rebuild.
